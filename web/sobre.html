Sobre o projeto

O Buscador CMTT torna pesquisáveis as atas do Conselho Municipal de Trânsito e Transporte de São Paulo. Um pipeline em Python lê os PDFs publicados pela Prefeitura, extrai o texto e a composição do Conselho, e carrega tudo em um banco de dados na nuvem. Este site consulta esses dados por meio de uma API própria.

Acessibilidade

O site foi feito seguindo as diretrizes WCAG 2.1 (nível AA) e o eMAG:

  • Tradução para Libras com o VLibras (ícone azul no canto da tela).
  • Botões A+ / A− para ajustar o tamanho do texto e modo de alto contraste.
  • Navegação completa pelo teclado (Tab, Enter, Espaço) com foco sempre visível.
  • Link “Pular para o conteúdo” e regiões (cabeçalho, menu, conteúdo, rodapé) marcadas para leitores de tela.
  • Mensagens de carregamento e de resultados anunciadas automaticamente por leitores de tela.
  • Todo gráfico tem uma tabela equivalente com os mesmos dados.
  • Cores com contraste mínimo de 4,5:1, layout responsivo para celular e respeito à preferência por menos animações.
